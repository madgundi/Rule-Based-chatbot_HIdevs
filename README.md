# 🤖 AI Rule-Based Chatbot

This is a simple, rule-based chatbot built using **Python** and **Streamlit**. It uses **regex pattern matching** to respond to user inputs with predefined answers. The chatbot covers a range of topics including AI, machine learning, general greetings, jokes, fun facts, and more!

---

## 🚀 Features

- ✅ Simple and fast regex-based chatbot engine
- 💬 Friendly, human-like responses
- 🧠 Predefined Q&A on AI, ML, NLP, blockchain, and more
- 🌐 Multilingual response capability (Hindi and Marathi)
- 🎨 Clean, modern Streamlit UI
- 🧪 Ready for unit testing with `pytest`
